🏥 Hospital Landing Page

A modern and fully responsive Hospital Landing Page built with HTML, CSS, and JavaScript.
The project features a clean and user-friendly interface, optimized for all devices, and showcases essential sections for a healthcare center.

🚀 Features

📱 Responsive Design: Works seamlessly on desktops, tablets, and mobile devices.

🎨 Modern & Friendly UI: Clean and professional design with focus on healthcare services.
